# Требования
## Внешние интеграции (с провайдером услуг по управлению IOT устройствами) должны удовлетворять следующим требованием:
- Наличие положений и политики обработки и защите перс. данных (ПД);
- Регулярное проведение аудита и внутренних проверок на соблюдение правил и политик обработки и защиты ПД;
- Должен быть заключен договор с обработчиком ПД (провайдером) в соответствие с ФЗ-152;
- Реализованы технические требования по контролю доступа к ПД;
- Реализовано шифрование на уровне хранения и передачи данных;
- Настроен мониторинг для оперативного реагирования на аномалии, а так же логгирование действий со стороны пользователей системы (создание, редактирование, изменение ПД);
- Наличие сформированного плана восстановления на случай сбоев.

## Аутентификация и авторизация
Для аутентификации и авторизации пользователей в системе управления умными устройствами будет использоваться 2FA:
- 1 фактор - по логин и паролю в домене групп клиентских сервисов (auth-service)
- 2 фактор - смс с проверочным кодом на привязанный номер телефона

## Взаимодействие
Взаимодействие между системами предприятия и внешней платформой будет реализовано с помощью HTTPS+TLS, что гарантирует безопасную передачу данных и минимизирует вероятность утечки конфиденциальных данных.
